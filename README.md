# jre-montreal-bridge

**JRE platform outreach lane** — Montreal comedy and cultural exchange, AI-safety dialogue,
Canada–US bridge initiative. Source-first: claims are tagged verified, partially verified,
disputed, or unverified before any outreach. Standard public intake only — no scraping of
private data, no leaked contacts, no adversarial routes.

**Pour le bien-être du peuple.**

## Episode ingestions

Verbatim, timestamped source records of public podcast episodes relevant to this lane. Each
folder holds the full transcript, the segment that prompted the ingestion, the host's
chapter list, and a retrieval log naming every route attempted including the failures.
